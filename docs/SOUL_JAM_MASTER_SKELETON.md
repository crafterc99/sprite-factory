# SOUL_JAM_MASTER_SKELETON

Generated by `tools/character_pipeline/skeleton-doc.mjs` from `lib/mocap/mhr-rigs/player.json.gz` (2026-09-29). Every Soul Jam player — the built-in ones and every Character Factory character — is bound to this skeleton.

| Fact | Value |
|---|---|
| Joints | **127** (MHR body model) |
| Root | `body_world` → `root` (pelvis) → spine `c_spine0…3` → `c_neck` → `c_head` |
| Units / scale | metres; reference height 1.83 m (bind pose, feet on y = 0; joint y from -0.051 to 1.815) |
| Axes | +Y up, the character faces **+Z**, its left is +X (glTF / three.js) |
| Rest pose | the bind pose below (`bindPos`, `bindRot` quaternions); per-character proportions are refitted onto the same joint set (`restJoints`, `boneLen`, `legLen`, `soleOffset` in each rig) |
| Twist joints | 40: l_lowleg_twist1_proc, l_lowleg_twist2_proc, l_lowleg_twist3_proc, l_lowleg_twist4_proc, l_upleg_twist0_proc, l_upleg_twist1_proc, l_upleg_twist2_proc, l_upleg_twist3_proc, l_upleg_twist4_proc, r_lowleg_twist1_proc, r_lowleg_twist2_proc, r_lowleg_twist3_proc, r_lowleg_twist4_proc, r_upleg_twist0_proc, r_upleg_twist1_proc, r_upleg_twist2_proc, r_upleg_twist3_proc, r_upleg_twist4_proc, r_wrist_twist, r_lowarm_twist1_proc, r_lowarm_twist2_proc, r_lowarm_twist3_proc, r_lowarm_twist4_proc, r_uparm_twist0_proc, r_uparm_twist1_proc, r_uparm_twist2_proc, r_uparm_twist3_proc, r_uparm_twist4_proc, l_wrist_twist, l_lowarm_twist1_proc, l_lowarm_twist2_proc, l_lowarm_twist3_proc, l_lowarm_twist4_proc, l_uparm_twist0_proc, l_uparm_twist1_proc, l_uparm_twist2_proc, l_uparm_twist3_proc, l_uparm_twist4_proc, c_neck_twist1_proc, c_neck_twist0_proc |
| Finger joints | 44 (thumb 0–3, index / middle / ring 1–3, pinky 0–3, tip nulls) |
| IK bones | none — IK is solved at runtime (`engine3d/contact-ik.mjs`, leg solver in `anim3d.mjs`) |
| Facial bones | none (see the facial standard note in docs/character-factory-plan.md §12) |
| Root motion | clips carry it separately (`rootMotion`: dx, dz, dyaw per frame, root space); the skeleton itself is posed in world space by the runtime |
| Skinning | 4 influences per vertex (the renderer's limit), weights normalised |
| Animation | keypoint clips (70 MHR70 keypoints) → `engine3d/mhr-skin.mjs` solves these 127 joints for any rig; no per-character retarget |
