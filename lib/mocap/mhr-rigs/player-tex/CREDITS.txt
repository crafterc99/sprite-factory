Player character (court3d "player") — how it was made

Mesh + textures: generated from the performer's own video (IMG_7870, motion
mo-mulp87wqvabn): source-frame crops → full-body A-pose front / back views
(GPT Image 2.5) → Hyper3D Rodin v2.5 via fal.ai (TAPose, de-lit PBR, 50K
triangles). Generated with the project's own API keys; use is subject to the
providers' terms (OpenAI, Deemos Hyper3D / fal.ai).

Skeleton + skin weights: Meta Momentum Human Rig (MHR), Apache-2.0 (see
../MHR-LICENSE.txt), shaped to the performer from the take's SAM 3D Body fit,
fitted to the mesh by scripts/mhr/fit_generated.py.
